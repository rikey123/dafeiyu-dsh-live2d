# DSH 设置保存与本地网关就绪检查

2026-11-14 收到保存设置返回 503、提示“本地语音服务尚未就绪”的报告。该文案来自 DSH 插件代理的 `ensure()` 前置检查，而非 DeepSeek TTS 的密钥或合成接口。

## 已确认的实例冲突

现场存在两个使用相同项目和 profile 的 DSH：额外手动启动的 3080 实例，以及用户从 DSH Launcher 启动的 3081 实例。二者争用固定的本地网关端口 8765；不同插件实例的内部鉴权令牌不同，不能直接借用另一实例的网关。失败实例的日志连续记录 `gateway_port_occupied`。

已停止额外的 3080 实例，保留 Launcher 的 3081 实例及其拥有的语音服务，没有更改用户密钥。检查时 3081 所属后端的健康检查和状态请求均返回 200；尚未取得该实例的真实设置保存成功记录，不能据此宣称保存端到端验收通过。此前 3080 实例的三次保存成功不作为 3081 的验收结果。

日常只使用 Launcher 管理的一套实例。从 Launcher 重新打开当前网页，不要沿用旧 3080 页面，也不要为测试再运行一次 `dsh web`。关闭网页标签不会停止对应 DSH 进程。以下代码加固需要通过 Launcher 正常停止再启动服务后加载；重启时不要再额外创建手动实例。

## 同时修复的生命周期漏洞

检查确认一处可复现的生命周期漏洞：已有受管理 supervisor 存活时，只要一次健康检查没有在 1.5 秒内成功，原代码就落入“8765 已被其他程序占用”的启动路径。因此短暂忙碌也会产生通用 503。现在保持进程所有权不变：

- 已拥有的存活 supervisor 共享恢复等待，最多 10 秒，不重复启动、不按端口杀进程；成功结果短暂缓存 1.5 秒，避免多个状态轮询重复探测。
- 首次启动仍单飞、最长 120 秒；退出/启动错误使缓存失效，卸载期间不允许发布迟到的子进程。
- 401/403 明确报告插件与网关鉴权不匹配，不自动更换密钥；外来占用不接管、不终止。
- 503 返回固定、脱敏的原因码：`gateway_busy`、`gateway_auth_mismatch`、`gateway_port_occupied`、`supervisor_failed` 等。`G:/dafeiyu/data/logs/dsh-plugin-runner.log` 追加固定故障码、时间和受管理 PID；不记录异常正文、请求体或密钥。
- 恢复等待在转发请求前发生，不重放保存请求，不发起试音或其他收费请求。

插件 41 项测试覆盖短暂恢复、持续忙碌后恢复、并发单飞、鉴权失败、外来进程、退出失效、卸载与完整请求体单次转发。G 盘为 exFAT，上游原生附件存储测试需要 NTFS，因此测试临时目录放 E 盘：

```powershell
$env:DAFEIYU_TEST_TMP='E:/Dafeiyu/tmp/dsh-tests'
$env:TEMP='E:/Dafeiyu/tmp'; $env:TMP=$env:TEMP
npm.cmd --prefix G:/dafeiyu/plugins/dsh test
```

真实 DSH 浏览器保存验证必须显式指定**当前正在使用的同一个 Launcher 实例**和该实例已授权的入口日志，不能使用旧实例的日志。脚本不会自行启动 DSH，也不会读取凭据文件；未提供当前合法入口时不运行浏览器验收：

```powershell
$env:DSH_TEST_ORIGIN='http://127.0.0.1:3081'
# 替换为 Launcher 当前实例实际输出入口的本地日志，不要创建第二套服务来获得入口。
$env:DSH_TEST_ENTRY_LOG='<当前 Launcher 实例的入口日志绝对路径>'
node G:/dafeiyu/scripts/check_dsh_settings_save.cjs
```

该脚本使用指定日志中对应实例的入口进行认证，不打印 token；在真实嵌入面板点击三次保存，其中一次临时切换 API 模式，最后恢复原模式。不会读取私有密钥、填写假密钥、开启麦克风、发送对话或请求合成。报告为 `G:/dafeiyu/.runtime/dsh-acceptance/settings-save.json`。如果异常退出，只恢复 `tts_mode`，不覆盖其他并发编辑或密钥。模式切换会关闭现有语音连接；恢复 GPU 模式时可能触发已有的模型预加载，应在空闲时验收，避免同时手工修改配置。
